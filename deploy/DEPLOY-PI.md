# Raspberry Pi: бот 24/7 дома

То же, что VPS, но железо ваше: нет аренды, нет зависимости от домашнего ПК.
Потребление — 2–5 Вт, тишина, размер с пачку сигарет.

## Что подойдёт

| Модель | Годится? | Комментарий |
|---|---|---|
| Raspberry Pi 5 (2–4 ГБ) | ✅ идеально | есть RTC, быстрая установка пакетов |
| Raspberry Pi 4 (2–4 ГБ) | ✅ хорошо | самый ходовой вариант |
| Raspberry Pi 3B+ | ✅ сойдёт | установка пакетов дольше, работе не мешает |
| Zero 2 W | ⚠️ можно | 512 МБ RAM — pandas ставится долго, но тянет |
| Zero (первый) | ❌ нет | слишком слабый |

Нужны: карта microSD 16–32 ГБ (A1/A2), официальный блок питания, корпус.
Проводной Ethernet надёжнее Wi-Fi.

## 1. Система

1. Скачайте **Raspberry Pi Imager** (raspberrypi.com/software).
2. Выберите Raspberry Pi OS **64-bit (Bookworm)**.
3. В настройках Imager (шестерёнка): задайте имя пользователя и пароль,
   включите SSH, при желании — Wi-Fi и локаль.
4. Запишите карту, вставьте, включите питание.

## 2. Подключение

```bash
ssh ВАШ_ПОЛЬЗОВАТЕЛЬ@raspberrypi.local
```

Если `.local` не находится — смотрите IP в админке роутера. Совет: закрепите
адрес за Pi в DHCP роутера, чтобы IP не менялся.

## 3. Копирование проекта

С вашего компьютера (PowerShell, из папки проекта):

```powershell
scp -r . ВАШ_ПОЛЬЗОВАТЕЛЬ@raspberrypi.local:~/gold-signal-bot
```

## 4. Установка одной командой

```bash
cd ~/gold-signal-bot
sudo bash deploy/install-pi.sh
```

Скрипт создаст пользователя `botuser`, окружение в `/opt/gold-signal-bot`,
поставит зависимости, включит службу с автозапуском и автоперезапуском.

## 5. Проверка

```bash
sudo -u botuser /opt/gold-signal-bot/venv/bin/python /opt/gold-signal-bot/bot.py --check
tail -f /var/log/gold-signal-bot.log
```

В Telegram отправьте боту `/status` — должен ответить.

## Особенности Raspberry (в отличие от VPS)

| Момент | Что делать |
|---|---|
| Карта microSD изнашивается | логи пишутся в `/var/log`, кэш — в `cache/`; при желании вынесите `cache/` на USB-флешку |
| Нет RTC у Pi 3/4 | время синхронизируется по NTP при загрузке; бот работает по UTC из данных, так что расхождение часов на пару секунд не влияет |
| Пропало питание | служба с `Restart=always` поднимется сама при загрузке; состояние в `state.json` |
| Wi-Fi отвалился | бот переживёт: сетевые ошибки логируются, следующий цикл повторит запрос |
| Перегрев/троттлинг | корпус с вентиляцией; нагрузка бота мизерная, троттлинг маловероятен |

## Обновление бота

```bash
cd ~/gold-signal-bot
scp ... (новые файлы)
sudo systemctl restart gold-signal-bot
```

## Важно

- После переезда на Pi **остановите бота на домашнем ПК** (иначе два процесса
  конфликтуют за `getUpdates`):
  `Unregister-ScheduledTask -TaskName GoldSignalBot -Confirm:$false`
- `config.json` содержит токен: права `600`, доступ только у вас.
- Бэкап состояния: `cp /opt/gold-signal-bot/state.json ~/state.backup.json`
