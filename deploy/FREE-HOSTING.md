# Бесплатный хостинг бота: варианты и честные ограничения

Бот работает 24/7 без вашего компьютера. Ниже — все реальные способы не платить,
с их минусами. «Бесплатно И надёжно» одновременно не бывает, поэтому выбирайте
по тому, что для вас важнее.

## Коротко

| Вариант | Бесплатно | Нужна карта | Надёжность | Команды в Telegram |
|---|---|---|---|---|
| **Oracle Cloud Always Free** | бессрочно | да (верификация, $0) | высокая | мгновенно |
| Google Cloud e2-micro | бессрочно | да | высокая | мгновенно |
| **GitHub Actions** | да | **нет** | средняя | с задержкой |
| **Termux на старом Android** | да | нет | зависит от телефона | мгновенно |
| Старый ноутбук / мини-ПК | да | нет | зависит от железа | мгновенно |

## 1. Oracle Cloud Always Free — лучший бесплатный вариант

Даёт **навсегда бесплатно** ARM-инстанс (до 4 ядер / 24 ГБ RAM) или x86 (1 ГБ).
Это полноценный сервер, бот живёт как на VPS.

Плюсы: настоящий 24/7, мгновенные команды, бесплатно без срока.
Минусы:
- при регистрации нужна банковская карта (списывают $0, проверка);
- регистрацию иногда отклоняют без объяснений — можно попробовать другой регион;
- Oracle может **отозвать простаивающий** инстанс (у нас нагрузка низкая — риск есть,
  но при работающей службе и трафике обычно живёт годами);
- ARM-инстанс: `pandas`/`numpy` ставятся из готовых колёс, сборки не требуется.

Инструкция — та же, что [DEPLOY.md](DEPLOY.md) (Ubuntu).

## 2. Google Cloud e2-micro — тоже бессрочно

Одна бесплатная микро-ВМ в отдельных регионах (us-central1, us-west1, us-east1),
1 ГБ RAM, 30 ГБ диска, 1 ГБ исходящего трафика в месяц. Боту хватает с запасом:
Telegram-поллинг — это единицы мегабайт в месяц.

Минусы: нужна карта, регион строго из списка (задержка до Telegram будет выше,
но для сигналов не критично).

## 3. GitHub Actions — бесплатно и **без карты**

Бот запускается по расписанию каждые 10 минут, делает один проход и выходит.
Всё уже настроено: `.github/workflows/signals.yml`, `config.ci.json`,
`requirements-bot.txt`. Нужно только добавить секрет `TELEGRAM_BOT_TOKEN`.

Плюсы: ноль платежей, ноль карт, ничего держать дома.
Минусы (важные):
- **задержка**: GitHub запускает cron с опозданием 5–20 минут. Сигнал может прийти
  позже, чем на живом сервере;
- **команды не мгновенные** — ответ на `/signal` придёт только на следующем запуске;
- **приватный репозиторий не подойдёт**: 2000 бесплатных минут/мес, а нам нужно
  ~4300 запусков. Значит репозиторий **публичный** (секреты в GitHub Secrets, но код
  и конфиг видны всем);
- расписание отключается после 60 дней без активности в репозитории;
- состояние хранится в кэше Actions; если кэш протухнет — бот потеряет открытые сделки
  (историю он не хранит на сервере).

Вывод: годится как «бесплатно и кое-как», не как основной вариант.

## 4. Termux на старом Android-телефоне

Если лежит без дела старый телефон — это полноценный Linux в кармане.

```bash
# в Termux
pkg update && pkg install -y python git
termux-wake-lock
pip install pandas numpy
# скопировать проект, затем:
python bot.py
```

Плюсы: бесплатно, мгновенные команды, дома.
Минусы: Android любит убивать фоновые процессы (нужен `termux-wake-lock` и
отключение оптимизации батареи), износ батареи, нужен Wi-Fi.

## 5. Старый ноутбук или мини-ПК

Самый простой путь, если есть лишняя техника: поставить Ubuntu и следовать
[DEPLOY.md](DEPLOY.md). Бесплатно, кроме электричества (10–20 Вт).

## Что выбрать

1. Есть карта и готовы к регистрации — **Oracle Cloud Always Free**.
2. Карты нет, но есть старый Android — **Termux** (команды мгновенные).
3. Карты нет и телефона нет — **GitHub Actions**, с задержкой сигналов.

Raspberry Pi — не «бесплатно», но разово и без аренды: [DEPLOY-PI.md](DEPLOY-PI.md).

## Важно в любом случае

Одновременно должен работать **только один** экземпляр бота, иначе Telegram
отдаёт одному из них ошибку 409 и команды теряются. Перед запуском на новом месте
остановите старого:

```powershell
Unregister-ScheduledTask -TaskName GoldSignalBot -Confirm:$false
```
