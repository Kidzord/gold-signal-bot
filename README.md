# Бот торговых сигналов (Telegram): золото + EURUSD + GBPUSD

Присылает в Telegram сигналы: точку входа, стоп, тейк и обоснование. Один бот — три инструмента:

| Инструмент | Ключ | Таймфрейм | Стратегия | Бэктест |
|---|---|---|---|---|
| XAUUSD | `gold` | H1 | пробой канала 24 бара | 302 сделки, PF 1.41, +0.24R |
| EURUSD | `eurusd` | H4 | пробой канала 48 баров | 89 сделок, PF 1.32, +0.19R |
| GBPUSD | `gbpusd` | H4 | пробой канала 24 бара | 107 сделок, PF 1.38, +0.22R |
| XAUUSD | `gold4h` | H4 | Flipped SNR | 122 сделки, PF 2.04, +0.52R |

Важно: на форексе H1 наши методы не работают (проверено — раздел 14 [REPORT.md](REPORT.md)),
поэтому пары торгуются только на H4. Подробности и оговорки — в отчёте.

Бот **не торгует сам** и не подключается к брокеру: он только считает уровни и присылает их.

## Быстрый старт (5 минут)

**1. Создайте бота**

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Придумайте имя и username (должен заканчиваться на `bot`).
3. Скопируйте токен вида `123456789:AAH...`.

**2. Вставьте токен**

Откройте `config.json` и заполните поле:

```json
"telegram_token": "123456789:AAH..."
```

Либо задайте переменную окружения `TELEGRAM_BOT_TOKEN` — она имеет приоритет.

**3. Запустите**

```powershell
cd C:\Users\admin\Documents\deepseek-harness\default-workspace\gold-signal-bot
python bot.py
```

На этой машине Python с нужными библиотеками лежит здесь:

```powershell
& "C:\Users\admin\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe" bot.py
```

Или просто двойным кликом по `run.bat`.

**4. Подпишитесь**

Напишите боту `/start`. Первый, кто это сделает, становится админом (если админ ещё не задан
через `ADMIN_ID`) — может подключить канал через `/channel`. Дальше сигналы приходят автоматически:
проверка каждые 10 минут по расписанию, но GitHub Actions может задерживать и пропускать запуски —
тогда сигнал может прийти позже закрытия бара.

> При первом запуске бот может сразу прислать сигнал, если он есть на последней закрытой свече,
> и будет отслеживать сделку до стопа/тейка.

## Команды бота

| Команда | Что делает |
|---|---|
| `/start` | окно настроек: депозит, риск на сделку, дневной стоп, стратегия (и подписка) |
| `/signal` | обзор по всем инструментам: цена, тренд, открытая сделка |
| `/signal eurusd` | детально по инструменту: ATR, канал, уровни MSNR |
| `/stats` | статистика бэктеста и live-сделок по всем инструментам |
| `/stats gbpusd` | статистика по одному инструменту |
| `/params gold` | правила стратегии инструмента |
| `/strategy gold msnr` | только админ: переключить стратегию инструмента |
| `/risk` | риск-лимиты: день/неделя/месяц и текущее состояние |
| `/status` | живость бота, свежесть данных по каждому инструменту |
| `/materials` | собранные посты из каналов (админ) |
| `/unsubscribe` | отписаться |
| `/channel <@name или -100…>` | только админ: дублировать сигналы в канал |

Ключи инструментов: `gold`, `eurusd`, `gbpusd`.

Для канала: добавьте бота администратором (достаточно права «Публикация сообщений»),
затем `/channel @my_channel`.

## Личные настройки подписчика

У каждого подписчика свои параметры — они задаются прямо в `/start` кнопками под карточкой
и не влияют на других:

* **Депозит** — пресеты `$5 000 / $10 000 / $25 000` или своя сумма (просто пришлите числом);
* **Риск на сделку** — `0.5% / 1% / 2%` от депозита (стоп стоит 1R, поэтому это и есть риск сделки);
* **Дневной стоп** — `3% / 5% / 10%`: при достижении бот ставит подписчика на паузу до конца
  торгового дня (граница дня — 17:00 Нью-Йорка) и до утра сигналы ему не шлёт;
* **Стратегия** — общая для всех, меняет админ.

Вместо «R» сигналы показывают результат в процентах и суммах от вашего депозита, например
`+0.80% (+$40)`, а в сигнале — риск и цель: `💰 Риск: 1.00% = $50`, `🎯 Цель: +2.00% = +$100`.
Лот не пишется: размер позиции зависит от брокера, я показываю только риск в деньгах.

Прогресс дня виден в самом окне `/start`: `📊 Сегодня: −5.50% (−$275) из −5%` — и там же
`⏸ пауза до конца дня`, когда стоп взят.

## Бот работает круглосуточно?

Нет: бот — это процесс на вашем компьютере, он запускается при входе в систему
и останавливается, когда компьютер выключен, спит или вы вышли из аккаунта.

- Пропущенные **сигналы** не воспроизводятся (бот смотрит только последнюю закрытую свечу).
- **Открытые сделки** не теряются: при старте бот проверяет все бары с момента входа
  и пришлёт отчёт, если стоп/тейк сработал во время простоя.

Чтобы сигналы шли всегда, перенесите бота на VPS — пошаговая инструкция
в [deploy/DEPLOY.md](deploy/DEPLOY.md). Варианты **без оплаты**
(Oracle Always Free, GitHub Actions, Termux) — в [deploy/FREE-HOSTING.md](deploy/FREE-HOSTING.md),
пошагово для GitHub — [deploy/GITHUB-ACTIONS.md](deploy/GITHUB-ACTIONS.md).
Для Raspberry Pi — [deploy/DEPLOY-PI.md](deploy/DEPLOY-PI.md). Важно: после переноса
**остановите бота на домашнем компьютере**, иначе два процесса будут конфликтовать
за `getUpdates`.

Есть режим одного прохода для запуска по расписанию:

```powershell
python bot.py --once   # просканировать, обработать команды и выйти
```

## Веб-панель

Лёгкая страница состояния — без Flask и зависимостей, на стандартном `http.server`.
Показывает инструменты, цены, открытые сделки с текущим R, риск-лимиты и время последнего бара.

Включается в `config.json`:

```json
"web": {"enabled": true, "host": "127.0.0.1", "port": 8080}
```

Открыть: `http://127.0.0.1:8080` (JSON: `/api/status`).
По умолчанию выключена и слушает только localhost. **Авторизации нет** — не выставляйте
порт наружу без файрвола.

## Надёжность и контроль

**Лимит риска по символу.** Золото у нас в двух инструментах (`gold` H1 и `gold4h` H4).
Без ограничения они могли открыть сделки одновременно и удвоить риск. Теперь на один
символ — не больше `max_risk_per_symbol` сделок (по умолчанию 2), независимо от того,
какие стратегии и таймфреймы их дали.

**Пропущенные сигналы.** Если бот не работал (GitHub Actions пропустил запуски, сервер
лежал), при следующем проходе он проверяет пропущенные бары и присылает отдельным
сообщением, какие сигналы сработали. Сделки при этом не открываются — это только
информация, чтобы вы понимали, что пропустили.

**Дайджест.** Раз в сутки (по умолчанию 18:00 UTC) приходит сводка: цены, тренд,
открытые сделки и результат за день/неделю/месяц. Отключается `"digest_hour": null`.

**Расширенная live-статистика.** `/stats` кроме числа сделок показывает live profit
factor и максимальную просадку — не только бэктест.

**Выбор стратегии переживает перезапуск.** Стратегии, выбранные через `/strategy`, теперь
пишутся в `state.json`: в GitHub Actions `config.json` пересоздаётся из `config.ci.json`
на каждом запуске, поэтому раньше выбор терялся через 10 минут. Повторная отправка одного
и того же сигнала после потери состояния блокируется по его `id` — дублей в чате не будет.

## Параллельный режим
У инструмента может быть **несколько стратегий сразу** — каждая ведёт свою сделку.
Включается полем `strategies` в `config.json` или командой:

```
/strategy gold breakout asian
```

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `strategies` | — | список стратегий инструмента (вместо `strategy`) |
| `max_parallel` | `2` | максимум одновременных сделок по одному инструменту |

Что это даёт (золото H1, breakout + asian на истории): 144R против 72R у одной стратегии,
просадка 17.7R против 13.4R, корреляция дневных результатов 0.31. То есть доходность
удваивается, а просадка растёт слабее — соотношение R/просадка 8.16 против 5.37.

Риск-лимиты при этом считаются по инструменту целиком, по всем его стратегиям.

## Сбор материалов из закрытых каналов

Публичные каналы читаются через `t.me/s/...`, а закрытые — нет. Поэтому бот умеет
принимать пересланные посты: перешлите ему в личку сообщения из канала (текст, скриншоты
и **PDF-методички**), он сложит их в `materials/ГГГГ-ММ-ДД/` и ответит, сколько собрано.
Проверить: `/materials`. PDF бот скачивает как документ — текст из него я извлекаю
(`pypdf` уже установлен), сканы без текстового слоя требуют OCR и не разбираются.

Второй способ — **автосбор**: добавьте бота администратором в канал, и каждый новый пост
будет сохраняться сам, без пересылки (история, к сожалению, не подтянется — только новые
посты). Третий способ — экспорт из Telegram Desktop в JSON: отправьте файл боту как документ.

Дальше по этим материалам можно разбирать правила стратегии и проверять их на истории —
как это было сделано с MSNR-каналом (раздел 11 в [REPORT.md](REPORT.md)) и с каналом
Fx_wad1m (раздел 12).

## Стратегия

**Вход в LONG** на закрытии бара, когда одновременно:

* закрытие выше максимума предыдущих N баров;
* цена выше EMA200 и EMA50 выше EMA200 (тренд вверх);
* ADX(14) > 18 (рынок не в «пиле»);
* ATR(14) выше 0.8 медианы ATR(200) (волатильность выше нормы).

**SHORT** — зеркально. Длина канала N: золото H1 — 24 бара, EURUSD H4 — 48, GBPUSD H4 — 24.

**Выход:** стоп 1.5×ATR, тейк 2R (2×риска), лимит по времени (48 баров на золоте, 30 на H4).
Одновременно — не больше одной сделки на инструмент.

Почему именно так и что проверялось — [REPORT.md](REPORT.md). Коротко: из трёх кандидатов
(откат к EMA, MACD-импульс, пробой канала) только пробой дал положительное ожидание
после издержек, а фильтр согласованности тренда сделал результат устойчивым во всех
четырёх временных отрезках. На форексе тот же метод работает только на H4 (раздел 14).

### Альтернатива: MSNR-уровни

В боте есть вторая стратегия — на «малайзийских» уровнях поддержки/сопротивления
(MSNR: зоны из подтверждённых пивотов, построенные по дневным барам, сигнал на пробое зоны).
Она тоже прибыльная, но слабее: 91 сделка, 42.9 % побед, PF 1.32, **+0.17R** на сделку
против +0.24R у пробоя канала. Зато просадка вдвое меньше (7.7R) и сигналов меньше.

Чтобы переключить стратегию инструмента, используйте команду (не нужен перезапуск):

```
/strategy gold msnr
/strategy eurusd channel
```

или поправьте поле `strategy` у нужного инструмента в `config.json`.
Ближайшие уровни MSNR при этом показываются в `/signal` независимо от выбранной стратегии —
они полезны как ориентиры для стопа и цели.

### Третий режим: MSNR + высокий RR

По мотивам разборов канала [Medovyk | MSNR](https://t.me/xaubymedovyk) добавлен вариант
с большой целью: стоп за дневной зоной, тейк **8R**, удержание до 5 суток.

| Стратегия | Сделок | Побед | PF | Ожидание | Просадка |
|---|---|---|---|---|---|
| `breakout` (по умолчанию) | 302 | 42 % | 1.41 | +0.24R | 14.4R |
| `msnr` | 91 | 43 % | 1.32 | +0.17R | 7.7R |
| `msnr_trend` | 68 | 34 % | 2.16 | **+0.76R** | **6.1R** |

Включается командой `/strategy msnr_trend`. Важная оговорка: у `msnr_trend` вся прибыль
получена на покупках (+62R), продажи минусовые (−10R) — это ставка на растущий тренд,
а не сбалансированная система. Подробный разбор — раздел 11 в [REPORT.md](REPORT.md).

## Настройки (`config.json`)

| Поле | По умолчанию | Описание |
|---|---|---|
| `telegram_token` | `""` | токен от @BotFather |
| `channel_id` | `null` | канал по умолчанию (можно задать командой `/channel`) |
| `display_tz` | `"Europe/Minsk"` | часовой пояс времени в сообщениях |
| `scan_seconds` | `300` | как часто проверять данные |
| `instruments` | `[]` | список инструментов; пусто = три из README |
| `risk_limits` | `{"daily_r": -2, "weekly_r": -3, "monthly_r": -7}` | лимиты убытка в R; при достижении новые сигналы по инструменту останавливаются |
| `max_parallel` | `2` | максимум одновременных сделок по инструменту (параллельный режим) |
| `max_risk_per_symbol` | `2` | максимум одновременных сделок по одному символу (все инструменты и стратегии) |
| `digest_hour` | `18` | час UTC для ежедневного дайджеста; `null` — выключить |
| `web` | `{"enabled": false, ...}` | веб-панель состояния |

Инструмент в `instruments` — объект:

```json
{
  "key": "eurusd",
  "symbol": "EURUSD=X",
  "name": "EURUSD",
  "timeframe": "4h",
  "strategy": "channel",
  "params": {"channel": 48},
  "spread": 0.00012,
  "max_bars": 30,
  "pip": 0.0001
}
```

* `timeframe`: `1h` или `4h` (H4 собирается из H1);
* `strategy`: `channel`, `breakout`, `asian`, `flip`, `fvg`, `msnr`, `msnr_trend`,
  `pullback`, `macd`;
* `params.channel` — длина канала для `channel`;
* `spread` — издержки в единицах цены (0.30 $ для золота, 0.00012 для EURUSD);
* `max_bars` — лимит удержания в барах своего таймфрейма;
* `pip` — 1.0 для золота (2 знака), 0.0001 для форекса (5 знаков и пипсы).

## Ограничения и риски

* **Не инвестиционная рекомендация.** Бот знает только заданные вами депозит, риск на сделку и
  дневной стоп — он показывает риск и цель в деньгах, но не считает лот и плечо: размер позиции
  каждый определяет сам.
* **Бэктест — не гарантия.** 2.3 года, ~300 сделок, просадка 14R и серия из 10 убытков подряд —
  это нормальная часть работы такой системы.
* **Данные.** Yahoo Finance отдаёт `GC=F` с задержкой (обычно 1–15 минут, иногда больше);
  это фьючерс, а не спот XAU/USD, поэтому уровни могут отличаться от цен вашего брокера
  на величину базиса (единицы долларов).
* **Рынок был растущим.** Большая часть прибыли в бэктесте получена на лонгах; на падающем
  рынке поведение может отличаться, хотя логика симметрична.
* **Один инструмент, одна сделка.** Пирамидинга, усреднений и хеджа нет.
